Project 1 API Documentation

This page documents all available API endpoints for Project 1. My website is called Countries Explorer. Back to Countries Explorer site

GET /getCountries

Retrieve a list of countries, optionally filtered by query parameters.

Supported Methods

  • GET
  • HEAD

Query Parameters

Name Type Required Description
region string optional Filter by region name
subregion string optional Filter by subregion name
name string optional Filter by exact country name

Returns

{ countries: [ ... ] } – an array of country objects.

Example

GET /getCountries?region=Asia Accept: application/json 200 OK { "countries": [ { "name": "India", "capital": "New Delhi", "region": "Asia", "subregion": "Southern Asia", "timezones": [...] } ] }

GET /getCountryByName

Retrieve details for a single country by name.

Supported Methods

  • GET
  • HEAD

Query Parameters

Name Type Required Description
name string required Name of the country

Returns

{ country: { ... } } – the matching country object, or 204 if not found.

Example

GET /getCountryByName?name=India Accept: application/json 200 OK { "country": { "name": "India", "capital": "New Delhi", "region": "Asia", ... } }

GET /getCountriesByTimezone

Retrieve countries that match a specific timezone abbreviation.

Supported Methods

  • GET
  • HEAD

Query Parameters

Name Type Required Description
timezone string required Timezone abbreviation (e.g. IST)

Returns

{ countries: [ ... ] } – list of countries in the timezone.

Example

GET /getCountriesByTimezone?timezone=IST Accept: application/json 200 OK { "countries": [ { "name": "India", ... } ] }

GET /getCountriesByCapital

Retrieve countries by their capital city name.

Supported Methods

  • GET
  • HEAD

Query Parameters

Name Type Required Description
capital string required Exact capital name

Returns

{ countries: [ ... ] } – list of countries matching the capital.

Example

GET /getCountriesByCapital?capital=Paris Accept: application/json 200 OK { "countries": [ { "name": "France", ... } ] }

POST /addCountry

Add a new country to the in-memory dataset. If the country already exists, it's updated instead (204 response).

Supported Methods

  • POST

Body Parameters

Name Type Required Description
name string required Country name
capital string required Capital city
region string required Region

Returns

  • 201 with message if added
  • 204 if updated existing entry
  • 400 if missing fields

Example

POST /addCountry Content-Type: application/json Accept: application/json { "name": "test1", "capital": "test 1 capital", "region": "test 1 region" } 201 Created { "message": "Added country test1", "id": "created" }

POST /editCountry

Edit fields for an existing country. Returns 404 if the country is not found.

Supported Methods

  • POST

Body Parameters

Name Type Required Description
name string required Name of the country to edit
(other fields) string optional Any other fields to update (e.g., capital, region)

Returns

  • 200 if updated
  • 404 if not found
  • 400 if missing name

Example

POST /editCountry Content-Type: application/json Accept: application/json { "name": "India", "capital": "New Delhi (Updated)" } 200 OK { "message": "Updated country India", "id": "updated" }

404 Not Found

Any request to a non-existent endpoint returns:

GET /nonexistent 404 Not Found { "message": "The page you are looking for was not found", "id": "notFound" }
